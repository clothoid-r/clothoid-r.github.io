운영진 전용 홈페이지 데이터 & 카드 관리 시스템

🔒 관리자 전용

해당 저장소에 Admin 또는 Maintain(운영진) 등급이 부여된 계정만 진입할 수 있습니다.

📌 안전한 저장소 전용 토큰(Fine-grained PAT) 발급 순서:

  1. GitHub 우측 상단 프로필 → Settings → 좌측 맨 아래 Developer settings 클릭
  2. Personal access tokens → Fine-grained tokens → Generate new token
  3. Resource owner를 저장소 소유자(clothoid-r 또는 본인 계정)로 선택
  4. Repository access에서 Only select repositories → clothoid-r.github.io 선택
  5. Permissions → Repository permissions → Contents를 Read and write로 설정 후 발급!

현재 로컬 서버(localhost) 환경에서 실행 중입니다.
